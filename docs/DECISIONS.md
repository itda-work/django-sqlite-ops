Litestream 은 복제본 경로·prefix 오타와 "복제본 없음"을 출력으로 구분하지 못한다(#3 실측). 생애 첫 배포에만 필요하다. 그 조합 밖에서는 무효과지만, 함수는 '첫 배포였음'을 기억하지 않으므로 이후 DB·메타가 함께 사라지고 prefix 까지 틀리면 같은 조합이 다시 성립한다. 그래서 **첫 배포 뒤에는 끈다**(운영 문서에 명시, #4) | 마스터 (#3) |

| D-15 | 2026-10-08 | boot 의 `--db`·`--meta-path` 는 **실제 경로만** 받는다: 부모 경로에 심볼릭 링크·`..` 가 없고, 정규화한 경로가 실제 경로와 같아야 한다. 아니면 사용법 오류로 거부하고 실제 경로를 쓰라고 안내한다. 경로 정규화가 Litestream 설정의 DB 식별자와 어긋나거나 다른 파일을 가리키는 문제가 리뷰 세 라운드 연속 나와서 계약을 좁힌다(#4). 부모 링크 배포 지원은 필요해지면 다시 연다 | 오케스트레이터 (#4, 마스터 위임) |
